# Live validation — 13 November 2026

These are dated observations through a local OpenVidia proxy using NVIDIA NIM, not a model-quality benchmark or an uptime guarantee. Inputs, outputs, session IDs, credentials and personal repository data are excluded. The tested inference proxy was commit `fa2806b`; the validator is included in this change.

## Protocol checks

Each cycle checks liveness, an SSE answer ending in `[DONE]`, a tool invocation and a follow-up consuming the tool result. The total cycle budget was 120 seconds, with at most two cycles running concurrently. Times cover the entire cycle, not time to first token.

## Real OpenCode tool execution

OpenCode version: `opencode v2.3.0`. Each private server used process-local provider configuration and an absolute temporary file path. Success required a completed `read` tool and an exact answer matching that file’s generated nonce. The per-command budget was 180 seconds.

| Requested model | File read completed | Exact answer | Command seconds |
|---|---|---|---:|
| `minimaxai/minimax-m3.1-flash` | True | True | 10.67 |
| `nvidia/nemotron-3.5-super-vl-120b-a12b` | True | True | 4.25 |
| `mistralai/mistral-large-4-1t-a52b` | True | True | 113.59 |

All three accepted integration runs passed. Earlier harness attempts sharing a database or using relative fixture paths were invalid: they produced database errors or searched the active workspace instead of the intended fixture. Those setup failures are not model-compatibility evidence.

An existing long-context OpenCode session also resumed through OpenVidia/Nemotron Ultra, used file tools and produced its requested report in 261.2 seconds. That establishes execution and output creation, not independent factual verification of generated research. Private inputs and outputs are not published.

## Scope and follow-up

The 72-hour monitor was running when this report was written; it had not completed. It must finish before any duration claim is made. These checks do not certify all catalog models, Windows/macOS, large-repository coding quality, or future NVIDIA availability. No inference model or automatic fallback policy was changed by the validator.

The test investigation also found and fixed a routing defect: a model-specific 504 could temporarily blacklist the shared host and hide the catalog. ASGI regressions now verify that the catalog and another model remain reachable.
